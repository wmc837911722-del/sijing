# 0.2.1 交互体验验收

日期：2026-10-08。环境：Windows、真实 Electron 窗口与本地 Python 后端。专项测试使用独立数据目录；交付更新时正常关闭旧版窗口，保留原有用户数据。

本记录覆盖源码界面和 Windows 0.2.1 打包程序的操作复验；打包验证范围见末节。

## 实际发现与修复

| 范围 | 复现的问题 | 修复后的行为 |
| --- | --- | --- |
| 模型表单、公共弹窗 | 按 Esc 关闭后焦点丢失；保存过程中仍能修改字段，关闭按钮没有禁用提示 | 关闭后恢复触发按钮焦点；提交时禁用字段和关闭按钮，Esc、遮罩不能误关；保留必填校验与连接失败反馈 |
| 仓库 | 1080×700 窗口中，无分隔长分支超出卡片，页面水平溢出 67px | 分支省略显示并可悬停查看全名；提交标识独立保留；任务错误长文本换行，复验水平溢出为 0；仓库状态统一为中文 |
| AI 问答 | 新建和切换会话可能丢失未发送草稿；重复新建留下空会话；连接失败后重载丢失原问题；问题长度未匹配接口上限 | 保留各会话草稿；未发送时不持久化空会话；失败问题可继续编辑；发送前阻止超过 8,000 字符的问题；后台回答不覆盖后续草稿 |
| 数据库、报表 | 导航或切换数据源丢失 SQL 草稿；迟到的查询结果可能出现在新数据源下；编辑后的 SQL 与旧结果容易混淆；报表失败反馈不在表单内 | 按数据源保留草稿和结果；结果绑定提交时的数据源及 SQL；报表失败在弹窗内说明并保留标题，返回查询页仍保留上下文；错误去除 Electron IPC 包装，保留真实业务原因 |
| Markdown 编辑 | 保存等待期间继续输入，会被先前提交的响应覆盖 | 本次只写入已提交快照；等待期间的新输入保留在编辑器中 |
| 业务地图、资料链接 | 最小窗口下右面板按钮无法打开面板；外部资料链接无响应 | 1080×700 可打开关联面板；HTTP(S) 资料链接经过桌面接口交给系统外链入口，本地可执行文件链接被拒绝 |

问答另验证了 Enter 发送、Shift+Enter 换行、输入法确认不误发、引用跳转、失败恢复和阅读旧消息时输入不抢滚动位置。布局检查覆盖 1080×700、1500×940 及浅深主题；模型弹窗和仓库重点检查最小窗口。隐藏窗口截图采用 Electron 原生捕获；表单专项使用减少动态效果设置，避免截图停留在主题过渡帧。

模型与数据库 JSON 按原字节复制到 `artifacts/`，复制前后 SHA-256 一致；其中原测试目录路径保持不变。数据库证据采用清理错误包装后的最新复验记录。最终还统一了页脚版本号，并让业务更新审阅在应用中禁用关闭按钮。

## 复验入口与限制

专项脚本为 [ux-forms.mjs](../scripts/ux-forms.mjs)、[ux-chat.mjs](../scripts/ux-chat.mjs)、[ux-data.mjs](../scripts/ux-data.mjs)、[ux-workspace.mjs](../scripts/ux-workspace.mjs)。数据库脚本设置 `UX_VERIFY=1` 运行断言；工作区脚本运行前需要 `npm run build`。各脚本使用独立测试数据。

- 本轮没有验证 macOS、Linux；Windows 操作验证针对安装包包含的 unpacked 程序，未实际操作安装、卸载和便携自解压流程。
- 模型成功、延迟及失败场景使用本机受控 HTTP 服务；数据库使用 SQLite。未据此声称真实付费模型、PostgreSQL 或 MySQL 环境已通过。
- 部分网络延迟、传输失败及无效报表凭据由测试脚本注入；真实本地服务和数据库仍参与对应流程。
- 外链测试拦截 `shell.openExternal` 并核对调用及协议限制，避免打扰用户；未实际验证系统浏览器打开远程网页。
- 草稿保留结论针对本次运行中的导航、会话切换和请求完成，不包含应用退出后的未发送草稿恢复。
