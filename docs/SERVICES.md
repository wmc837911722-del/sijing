# 企业部署、技术支持与定制开发

思径帮助研发与技术支持团队从代码建立可编辑、可追溯的业务知识，并按需连接只读数据查询。当前仍在开发预览阶段，以下为拟提供的服务范围，具体是否可交付、价格和时间需结合项目评估。

## 适合咨询的需求

- 接手陌生或遗留系统，希望梳理一个明确业务域的规则、流程和代码依据。
- 需要配置内网 Git、公司代理/CA、获准模型或只读数据库。
- 希望把业务知识问答接入现有支持流程或 MCP 工具。
- 需要特定数据口径、报表或连接器，以及后续升级和问题排查协助。

## 合作方式

先明确一个可验收的问题，再确定有限试点。可以约定的交付包括接入配置说明、带来源的业务笔记、待确认项、人工验收案例和定制功能。覆盖范围、数据访问方式、交付时间、费用、代码归属及支持责任在开始前确认。

模型产生的解释需要证据核对，不能承诺自动理解所有代码或完全替代业务专家。内网仓库接入不等于模型离线运行；代码分析使用的服务地址必须得到企业授权，模型 API 与其他第三方费用另行明确。

## 咨询入口

如需讨论部署、技术支持或定制开发，请用公开议题描述需求。[填写企业服务咨询表](https://github.com/wmc837911722-del/sijing/issues/new?template=service-inquiry.yml)

首次咨询只需提供可公开的信息：希望解决的问题、系统技术栈及部署类型、期望交付物和主要限制。请勿提交 API Key、账号密码、客户数据、未脱敏源码或内部地址；详细材料应在约定适当渠道及授权后交换。

开源核心使用 MIT 许可，自助使用和商业使用无需购买这些服务。付费服务针对实际部署、支持和定制工作；完整开放安排见[开源与获客策略](OPEN-SOURCE-STRATEGY.md)。
